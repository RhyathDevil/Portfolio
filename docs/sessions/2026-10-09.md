## Decisions

- **Separate HTML files per language (`/` and `/de/`) instead of a JS toggle.** This gives a correct `lang` attribute for screen readers, a separate URL per language and works without JS. Cost: every text change has to be made twice.
- **Root-relative paths (`/assets/...`) instead of relative paths.** Paths stay the same at any folder depth, so copying pages into `de/` doesn't break them and `404.html` works on deep URLs. This requires a local server rooted at `public/`.
- **No PHP.** All interactivity is client-side JS. The contact form uses Netlify Forms. If server logic is ever needed, Netlify Functions are written in JS too.
- **`public/` as publish directory.** Planning files and docs stay in the repository but are not published.
- **Build the shared page skeleton once in `index.html`**, then copy it to the other pages (task 1.3) after the base CSS is stable.
- **The portfolio itself is the first project.** It is documented through a project journal (`docs/projekt-tagebuch.md`, not yet created).
- **Honeypot instead of CAPTCHA** for spam protection, because CAPTCHAs are an accessibility barrier.
