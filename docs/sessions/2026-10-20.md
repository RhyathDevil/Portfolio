## Decisions

- **Line endings are enforced in the repository, not in the IDE.** Reinstalling WebStorm reset the project code style to "Default" (CRLF on Windows), and `index.html` was saved with CRLF again. `.editorconfig` and `.gitattributes` survive reinstalls and apply on both PCs.
- **No private notes in HTML comments.** Anyone can read the page source. Reminders go into `AUFGABEN.md` ("Später anpassen") or the project journal.
- **Homepage title is "Name – Role".** Every other page uses "Page – Name".
- **Description without "in Germany"**, with accessibility as the focus (variant B). It promises no demos until some exist.
- **Demos are chosen per project and are optional.** Every demo has a text alternative. Videos are self-hosted for privacy, the same reason the fonts are hosted locally.
- **Install instructions live in each project's README**, not on the website, so they are maintained in one place.
