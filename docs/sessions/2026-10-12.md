## Decisions

- **The local Python server is used for development, and nginx stays unchanged.** nginx (port 80, root `/srv/http`) and the Python server (port 8000, root `public/`) run side by side. nginx would serve the site under a subfolder (`/Portfolio/public/`), which breaks root-relative paths. Reconfiguring it has no benefit, because neither server understands Netlify's `_redirects`, and it would risk the other projects under `/srv/http`.
- **WebStorm's "Open in Browser" is not used**, for the same reason: it serves from `localhost:63342/Portfolio/...`.
- **The custom 404 page and `_redirects` are tested on Netlify only.** Python's `http.server` shows its own error page.
